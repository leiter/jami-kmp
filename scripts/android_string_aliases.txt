# Aliases for scripts/sync_android_strings.py
#
# A KMP-only string key whose English text is identical to a jami-client-android string under a
# different key name. The sync script takes that Android string's translations for the KMP key.
#
#   kmp_key = android_key
#
# The script re-checks on every run that both English texts still match (ignoring case and
# %s/%1$s numbering), and skips the alias if they have drifted apart. An alias only fills a
# missing translation; it never overwrites an existing one, so hand-made German stays.
#
# Identical English is not identical meaning: every line below was reviewed against the Android
# key's context and its German/French/Spanish translations. Rejected candidates are kept at the
# bottom so nobody re-adds them.
#
# Exclusions skip one bad upstream translation:
#
#   ! <values-folder> <kmp_key>   # reason
#
# Reviewed 2026-11-11 against jami-client-android f36fae6 (2026-10-27).
